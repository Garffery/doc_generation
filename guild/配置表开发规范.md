# 配置表开发规范

## 一、数据构建方式（核心）

### 方式一：运营活动配置 → 列表 + 元组

**适用场景**：运营活动、抽奖、商店、任务等配置

**格式**：

```erlang
函数名() -> [
    {字段1, 字段2, 字段3, ...},
    {字段1, 字段2, 字段3, ...},
    ...
].
```

**示例**：

```erlang
%% 抽奖配置列表
get_draw_list() -> [
    {[1,500], 1, {112735,1,0,0,0}, 80, 500, 10, 600, 2, 1, 0, 0, 1, 0, 0},
    {[1,500], 2, {112736,1,0,0,0}, 20, 200, 10, 400, 1, 2, 1, 13, 1, 0, 0},
    {[501,9999], 18, {124004,1,0,0,0}, 80, 500, 10, 600, 2, 1, 0, 0, 1, 0, 0}
].

%% 商店配置列表
get_shop_list() -> [
    {1, [1,500], [{112601,2,0,0,0}], 20, 9999, 0},
    {2, [1,500], [{112602,1,0,0,0}], 40, 500, 0},
    {3, [1,500], [{112603,1,0,0,0}], 80, 10, 1}
].

%% 任务配置列表
get_lucky_task_2620() -> [
    {1, [1,9999], 1, <<"累计充值999彩钻"/utf8>>, [{charge_diamond,999}], [], 1, [{190101,10,0,0}], [], 0, 0, 1, 0, 0},
    {2, [1,9999], 1, <<"累计消费1280彩钻"/utf8>>, [{cost_diamond,1280}], [], 1, [{190101,10,0,0}], [], 0, 0, 1, 0, 0}
].
```

### 方式二：功能类配置 → Record

**适用场景**：系统功能、属性配置、模板数据等

**格式**：

```erlang
-include("xxx.hrl"). %% 引入record定义

get(Key) ->
    #record名{
        字段1 = 值1,
        字段2 = 值2,
        ...
    }.

get(_) -> [].
```

**示例**：

```erlang
-include("example.hrl").

get_attr(1, 4) ->
    #example2{
        int_type = 1,
        int_key2 = 4,
        string_type = <<"天王盖地虎"/utf8>>,
        float_type = 1.23,
        bool_type = false,
        arr_type = [1,2,4]
    };

get_attr(2, 2) ->
    #example2{
        int_type = 2,
        int_key2 = 2,
        string_type = <<"小苑炖蘑菇"/utf8>>,
        float_type = 2.354,
        bool_type = true,
        arr_type = [56,77]
    };

get_attr(_, _) -> [].
```

## 二、选择指南

| 场景 | 构建方式 | 原因 |
|------|----------|------|
| 运营活动配置 | 列表 + 元组 | 数据量大、结构相对固定、便于遍历 |
| 抽奖/商店/任务 | 列表 + 元组 | 同上 |
| 系统功能配置 | Record | 字段语义清晰、便于维护 |
| 属性/模板数据 | Record | 字段多、需要明确字段名 |
| 单条数据查询 | Record | 按key直接返回结构化数据 |

## 三、数据说明

配置表支持以下数据类型：

### 1. 基础类型

| 类型 | 格式 | 示例 | 说明 |
|------|------|------|------|
| 整数 | 普通数字 | `100`, `-9999` | 支持正整数、负整数、零 |
| 浮点数 | 带小数点 | `1.23`, `-2.354` | 常用于概率、倍率等 |
| 布尔值 | 0/1 或 true/false | `true`, `false` | 逻辑判断使用 |
| 原子 | 直接写 | `lv_type`, `charge_diamond` | 用于标识符、配置键 |

### 2. 复合类型

| 类型 | 格式 | 示例 | 说明 |
|------|------|------|------|
| 数据区间 | 两元素列表 | `[1, 500]`, `[1, 9999]` | 表示ID范围、等级范围 |
| 物品 | 5元素元组 | `{112735,1,0,0,0}` | 物品ID, 数量, 绑定, 类型, 保留字段 |
| 物品列表 | 元组列表 | `[{112735,1,0,0,0}]` | 多个奖励道具 |
| 条件列表 | 元组列表 | `[{charge_diamond,999}]` | 多个条件、触发条件 |

### 3. 常用数据结构示例

**物品奖励**：

```erlang
{112735, 1, 0, 0, 0}  %% {物品ID, 数量, 绑定, 类型, 保留字段}
```

**范围区间**：

```erlang
[1, 500]       %% ID从1到500
[1, 9999]      %% 所有玩家（1到9999级）
[501, 9999]    %% ID从501到9999
```

**任务条件**：

```erlang
{charge_diamond, 999}   %% 累计充值999彩钻
{cost_diamond, 1280}    %% 累计消费1280彩钻
```

**配置项**：

```erlang
get_config(lv_type) -> 3;            %% 等级类型
get_config(consume_price) -> 99;     %% 消耗价格
get_config(draw_item) -> 125904;     %% 抽奖道具ID
```

## 四、注意事项

1. **禁止手动修改**：配置文件由Excel自动生成
2. **UTF8编码**：中文必须用 `<<"文本"/utf8>>`
3. **默认返回值**：`get()` 必须返回 `[]` 作为默认值
4. **运营活动配置**：用列表+元组，便于遍历和批量处理
5. **功能配置**：用Record，字段语义清晰
